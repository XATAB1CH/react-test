# Клёв Задачник

Одностраничное приложение на React и Vite. Задачи можно добавлять, отмечать выполненными, удалять, искать и фильтровать. Список сохраняется в браузере. При первом открытии показаны пять примеров.

## Запуск

Для команд из Makefile нужны Node.js 22 или новее с npm и GNU Make. Запускайте команды из папки проекта.

| Действие | macOS | Windows (PowerShell или cmd) |
| --- | --- | --- |
| Запустить приложение | `make run-macos` | `make run-windows` |
| Собрать приложение в `dist/` | `make build` | `make build` |
| Собрать и проверить production-версию | `make preview` | `make preview` |

Команды автоматически устанавливают зависимости из `package-lock.json`. Откройте адрес, который Vite выведет в терминал. По умолчанию для разработки используется `http://127.0.0.1:5173/`, для проверки сборки — `http://127.0.0.1:4173/`.

Если GNU Make не установлен, выполните `npm ci` и `npm run dev` на macOS либо `npm.cmd ci` и `npm.cmd run dev` в Windows. Для сборки замените `run dev` на `run build`.
